# SignUpSource Prototype

This directory contains prototype files for the SignUpSource component, which helps collect information about where users find your website.

## Files Included

1. **index.html** - A basic demo page showing the SignUpSource modal
2. **style.css** - Styling for the demo page
3. **script.js** - JavaScript code that implements the demo functionality
4. **signupsource.min.js** - A simulated version of the CDN script that would be included in websites
5. **implementation-example.html** - A more detailed example showing how to implement SignUpSource in a real website

## How to Use

1. Open any of the HTML files in a web browser to see the SignUpSource modal in action
2. The demo shows how a website can collect information about where users came from
3. Click the "Simulate New User" button to trigger the modal

## Features Demonstrated

- Modal popup for new users
- Configurable title, description, and button text
- Customizable list of check items
- Callback function for handling selected items
- Basic styling and animations

## Implementation Notes

The prototype demonstrates the key concepts described in the SignUpSource README:

- Adding the script to a website
- Checking if a user is new
- Calling the `signupsource()` function with appropriate options
- Handling the user's selections with a callback function

This prototype serves as a visual representation of how the SignUpSource component works and how it can be integrated into websites.
