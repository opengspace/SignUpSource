SignUpSource Implementation Example

Step 1: Include the script

Add the SignUpSource script to your website by including the following line in your HTML:

<script src="https://cdn.jsdelivr.net/npm/signupsource@latest/dist/signupsource.min.js"></script>

For this example, we're using a local version of the script:

<script src="signupsource.min.js"></script>

Step 2: Check for new users

When a new user visits your site, call the signupsource function with your configuration:

// Check if user is new
const isNewUser = !localStorage.getItem('returning_user');

if (isNewUser) {
    // Configure SignUpSource
    signupsource({
        id: 'your-website-id',
        title: 'How did you find us?',
        description: 'We\'d love to know how you discovered our site!',
        buttonText: 'Submit',
        checkItems: [
            { id: 'google', label: 'Google Search' },
            { id: 'social', label: 'Social Media' },
            { id: 'friend', label: 'Friend Recommendation' },
            { id: 'blog', label: 'Blog or Article' },
            { id: 'other', label: 'Other' }
        ],
        callback: function(userCheckedItems) {
            console.log('User selected sources:', JSON.stringify(userCheckedItems));
            // You can do additional processing here
            localStorage.setItem('returning_user', 'true');
        }
    });
}
